Sobre este sitio

Este sitio es la Práctica 1 de la asignatura Desarrollo Basado en Plataformas. Tiene cuatro páginas: esta portada, una página de información, el horario de clases en una tabla y un formulario de registro. Se corrigió para cumplir los estándares de la W3C: HTML válido, CSS en un archivo aparte, etiquetas semánticas y las pautas de accesibilidad WCAG 2.2 nivel AA.
